# Feature Status

What a user can actually do in StudViro today, by audience. This is the product view;
`docs/Product Plan.md` is the record of what was built and `docs/STATUS.md` is the handoff
note. Update the affected row in the same commit as the work, per the `ship-backlog-step`
skill.

StudViro is the system of record (ADR 0024). There is no upstream, nothing arrives by
import, and every row below describes something a person enters or does here.

Last updated: 2026-10-24

## States

| State      | Meaning                                                               |
| ---------- | --------------------------------------------------------------------- |
| `Live`     | Usable end to end by its audience: API, screen, tests, strings keyed  |
| `Partial`  | Usable, but a named part of the capability is missing                 |
| `API only` | The endpoint works; no screen sits behind it, so nobody can use it    |
| `Planned`  | Not started                                                           |
| `Blocked`  | Waiting on access, credentials or a decision outside the repositories |
